Autonomous Agribot Smart Farming Rover

Domain: Precision Agriculture, Embedded Robotics & Wi-Fi Web Automation

Project Overview & Scope

Developing a smart agricultural rover system powered by dual ESP32 microcontrollers. Designed to automate field navigation, tilling, soil watering, and mechanical weed uprooting without requiring heavy AI hardware or external apps. Controlled directly through a custom responsive mobile browser dashboard.

Working Principle

The ESP32 hosts an onboard Wi-Fi Access Point running a lightweight C++ web server. Commands sent from a smartphone browser execute asynchronous HTTP endpoints (`/control?cmd=...`), instantly triggering L298N motor driver channels, water pump relays, and servo/motor-driven mechanical uprooting actuators.

Tech Stack & Hardware

    ESP32 DevKit V1 C++ / Arduino IDE L298N Motor Driver HTML / JavaScript Web Server ArduinoOTA Wireless Update
agribot_master_firmware.ino 
/*
  Project: Autonomous Agribot Smart Farming Rover
  Controller: ESP32 DevKit V1
  Author: Maha Saran
*/
#include <WiFi.h>
#include <WebServer.h>
#include <ArduinoOTA.h>

const char* ssid = "Agribot_Rover_AP";
const char* password = "agribot1234";
WebServer server(80);

const int IN1 = 4;
const int IN2 = 16;
const int IN3 = 17;
const int IN4 = 5;
const int UPROOT_IN1 = 22;
const int UPROOT_IN2 = 23;

void handleRoot() {
  String html = "<!DOCTYPE html><html><head><title>Agribot Dashboard</title>";
  html += "<meta name=\"viewport\" content=\"width=device-width, initial-scale=1\">";
  html += "<style>body{background:#0f172a;color:#fff;font-family:sans-serif;text-align:center;padding:20px;}";
  html += "button{background:#10b981;color:#0f172a;border:none;padding:15px 25px;margin:10px;font-size:16px;font-weight:bold;border-radius:12px;cursor:pointer;}</style>";
  html += "</head><body>";
  html += "<h1>Agribot Control Center</h1>";
  html += "<br><button onclick=\"fetch('/control?cmd=forward')\">FORWARD</button><br>";
  html += "<button onclick=\"fetch('/control?cmd=left')\">LEFT</button> ";
  html += "<button onclick=\"fetch('/control?cmd=stop')\">STOP</button> ";
  html += "<button onclick=\"fetch('/control?cmd=right')\">RIGHT</button><br>";
  html += "<button onclick=\"fetch('/control?cmd=reverse')\">REVERSE</button><br><br>";
  html += "<button style=\"background:#f59e0b;\" onclick=\"fetch('/control?cmd=uproot')\">TRIGGER UPROOT CLAW</button>";
  html += "</body></html>";
  server.send(200, "text/html", html);
}

void handleControl() {
  String cmd = server.arg("cmd");
  if (cmd == "forward") {
    digitalWrite(IN1, HIGH); digitalWrite(IN2, LOW);
    digitalWrite(IN3, HIGH); digitalWrite(IN4, LOW);
  } else if (cmd == "uproot") {
    digitalWrite(UPROOT_IN1, HIGH); digitalWrite(UPROOT_IN2, LOW);
    delay(1500);
    digitalWrite(UPROOT_IN1, LOW); digitalWrite(UPROOT_IN2, HIGH);
    delay(1500);
    digitalWrite(UPROOT_IN1, LOW); digitalWrite(UPROOT_IN2, LOW);
  }
  server.send(200, "text/plain", "OK: " + cmd);
}

void setup() {
  Serial.begin(115200);
  pinMode(IN1, OUTPUT); pinMode(IN2, OUTPUT);
  pinMode(IN3, OUTPUT); pinMode(IN4, OUTPUT);
  pinMode(UPROOT_IN1, OUTPUT); pinMode(UPROOT_IN2, OUTPUT);
  WiFi.softAP(ssid, password);
  ArduinoOTA.begin();
  server.on("/", handleRoot);
  server.on("/control", handleControl);
  server.begin();
}

void loop() {
  server.handleClient();
  ArduinoOTA.handle();
}

FILTERIQ – Smart Greywater Recycling System

Domain: IoT, Embedded Systems & Environmental Engineering

Project Overview & Working Principle

Engineered an automated greywater filtration and recycling system featuring real-time sensor telemetry and Over-The-Air (OTA) firmware updates. Water flows through multi-stage media (activated carbon and sand) monitored by digital flow sensors and float switches, automatically regulating booster pump relays to ensure safe recirculation.

Tech Stack & Architecture

ESP32 Wi-Fi C++ / ArduinoOTA Flow Sensors & Relays
filteriq_iot_system.ino 
/*
  Project: FILTERIQ – Smart Greywater Recycling System
  Controller: ESP32
  Author: Maha Saran
*/
#include <WiFi.h>
#include <WebServer.h>
#include <ArduinoOTA.h>

const char* ssid = "FilterIQ_Network";
const char* password = "filteriq_secure";
WebServer server(80);

const int FLOW_SENSOR_PIN = 14;
const int PUMP_RELAY_PIN = 26;
volatile int pulseCount = 0;
float calibrationFactor = 4.5;
float flowRate = 0.0;
unsigned long oldTime = 0;

void IRAM_ATTR pulseCounter() { pulseCount++; }

void handleTelemetry() {
  if ((millis() - oldTime) > 1000) {
    detachInterrupt(FLOW_SENSOR_PIN);
    flowRate = ((1000.0 / (millis() - oldTime)) * pulseCount) / calibrationFactor;
    oldTime = millis();
    pulseCount = 0;
    attachInterrupt(FLOW_SENSOR_PIN, pulseCounter, FALLING);
  }
  String json = "{ \"system\": \"FILTERIQ\", \"flow_rate_L_min\": " + String(flowRate) + " }";
  server.send(200, "application/json", json);
}

void setup() {
  Serial.begin(115200);
  pinMode(FLOW_SENSOR_PIN, INPUT_PULLUP);
  pinMode(PUMP_RELAY_PIN, OUTPUT);
  attachInterrupt(FLOW_SENSOR_PIN, pulseCounter, FALLING);
  WiFi.begin(ssid, password);
  ArduinoOTA.begin();
  server.on("/data", handleTelemetry);
  server.begin();
}

void loop() {
  server.handleClient();
  ArduinoOTA.handle();
}

LaunchPad_CoinCollector.luau 
--[[
  Project: Custom Coin Collector & Launch Pad 3D Game
  Environment: Roblox Studio (Luau)
  Author: Maha Saran
]]--

local coin = script.Parent
local launchPad = workspace:WaitForChild("LaunchPad")
local launchForce = 120

local function onCoinTouch(hit)
	local character = hit.Parent
	local humanoid = character:FindFirstChildOfClass("Humanoid")
	if humanoid then
		local player = game.Players:GetPlayerFromCharacter(character)
		if player then
			local stats = player:FindFirstChild("leaderstats")
			if stats then
				local score = stats:FindFirstChild("Coins")
				if score then score.Value += 1 end
			end
		end
		coin:Destroy()
	end
end
coin.Touched:Connect(onCoinTouch)

local function onLaunchPadTouch(hit)
	local character = hit.Parent
	local rootPart = character:FindFirstChild("HumanoidRootPart")
	if rootPart then
		rootPart.AssemblyLinearVelocity = Vector3.new(0, launchForce, 0)
	end
end
launchPad.Touched:Connect(onLaunchPadTouch)
